## Notes

1. **There is exactly one custom backend operation in the whole product**: the `realtime-token` edge function. Every other "integration" visible in the console is a label in a static array.
2. The realtime agent has **no tool calling**. The prompt tells the model to behave as if it had system access to a mock account (`inventory.ts:118-120`). This is honest in the prompt ("say honestly that this is a demonstration environment") but the console's tool traces, p95 latencies and success rates are unrelated fiction.
3. Nothing in the codebase sends an email, SMS, webhook, or writes to a CRM.
